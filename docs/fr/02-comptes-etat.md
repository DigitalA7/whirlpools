# Comptes et état

Whirlpools organise l’état autour de comptes Solana : configuration, pool, positions, tick arrays et vaults. Les adresses et leurs relations sont dérivées déterministiquement. Une intégration doit vérifier les propriétaires de comptes, les PDA attendus et les mints avant de construire une instruction.
