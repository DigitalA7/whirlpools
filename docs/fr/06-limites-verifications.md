# Limites et vérifications

Ce parcours couvre l’architecture Rust, les comptes, les bins, les échanges, les frais et les SDKs présents dans le dépôt. Il ne couvre pas un déploiement ni une validation on-chain. Les garanties dépendent du programme déployé, de l’identifiant de programme, des versions de clients et de la fraîcheur des comptes lus.

Aucune installation, compilation ou exécution n’a été réalisée dans ce parcours documentaire. Pour approfondir, consulter les tests et audits référencés dans le dépôt source.
